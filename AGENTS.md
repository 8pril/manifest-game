# Project Working Rules

## AI Usage Logging

For any material work on this NAN 2026 project, update `docs/ai-usage-log.md` before giving a final response.

Material work includes:

- Game design decisions
- Feature implementation
- Code generation or refactoring
- Bug fixing
- Asset generation or selection
- Balance tuning
- Prompt-assisted writing
- Submission document drafting
- Build, deploy, or release preparation

Each log entry should record:

- Date and task title
- Project phase
- AI tool used
- User instruction or prompt summary
- AI output summary
- Human review criteria
- What was accepted, changed, or rejected
- Whether it was reflected in the game or documents
- Related files
- Remaining issues

If no AI log update is needed, explicitly state why in the final response.

## End-of-Task Checklist

Before final response:

- Confirm whether the task changed project decisions, code, documents, assets, or submission material.
- If yes, update `docs/ai-usage-log.md`.
- If an action item changed, update `docs/action-tracker.md`.
- Mention the updated log entry in the final response.

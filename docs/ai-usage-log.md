# AI 활용 기록 로그

이 파일은 최종 제출물인 `AI 활용 기술 문서` 작성을 위한 원천 기록이다.  
AI를 사용한 모든 의사결정, 프롬프트, 결과, 사람의 검토 및 수정 내용을 이곳에 누적한다.

## 기록 원칙

- AI를 사용한 즉시 기록한다.
- 프롬프트는 가능한 한 원문에 가깝게 남긴다.
- AI 결과물을 그대로 사용했는지, 수정했는지, 폐기했는지 명확히 적는다.
- 게임에 반영된 결과와 반영되지 않은 결과를 구분한다.
- 저작권, 라이선스, 외부 출처 관련 내용은 빠뜨리지 않는다.
- 주요 작업이 끝났는데 기록할 내용이 없다고 판단한 경우, 최종 응답에서 그 이유를 명시한다.
- 이 프로젝트의 작업 규칙은 루트의 `AGENTS.md`에도 기록되어 있으며, 작업 종료 전 이 파일 업데이트 여부를 확인한다.

## 단계별 기록 액션

### Phase 0. 기획 압축

- [ ] AI에게 기존 기획의 핵심 루프 요약을 요청했다.
- [ ] AI가 제안한 스코프 축소안을 검토했다.
- [ ] 채택한 기능과 제외한 기능을 기록했다.
- [ ] 사람이 최종 결정한 이유를 기록했다.

기록해야 할 내용:

- 기획 요약 프롬프트
- AI가 제안한 핵심 재미 요소
- 예선 빌드에서 제외한 기능
- 최종 선택 이유

### Phase 1. 프로젝트 세팅

- [ ] 기술 스택 후보 비교에 AI를 사용했다.
- [ ] 선택한 스택과 선택 이유를 기록했다.
- [ ] AI가 생성 또는 제안한 초기 구조를 기록했다.
- [ ] 사람이 수정한 프로젝트 구조를 기록했다.

기록해야 할 내용:

- Vite, Phaser, Canvas 등 후보 비교
- 배포 방식 결정 이유
- 초기 폴더 구조
- AI 제안 중 폐기한 항목

### Phase 2. 핵심 플레이 구현

- [ ] 핵심 게임 루프 구현에 AI를 사용했다.
- [ ] 주요 시스템별 프롬프트를 기록했다.
- [ ] AI 코드 제안을 검토하고 수정한 내용을 기록했다.
- [ ] 버그 수정 과정에서 AI를 사용한 경우 재현 조건과 해결 방식을 기록했다.

기록해야 할 내용:

- 플레이어 조작 구현
- 전투/점수/자원/턴/웨이브 로직
- 승리/패배 조건
- 버그 원인과 수정 이유

### Phase 3. 콘텐츠 채우기

- [ ] 무기, 상태이상, 콤보 발동 스킬, 보조능력 데이터 작성에 AI를 사용했다.
- [ ] 태그 기반 장착 가능 여부와 조합 규칙 설계에 AI를 사용했다.
- [ ] 사람이 편집, 검증, 밸런싱한 내용을 기록했다.
- [ ] 최종 게임에 반영된 AI 코딩 에이전트 활용 사례를 정리했다.

기록해야 할 내용:

- AI로 만든 무기 데이터, 보조능력 데이터, 적 패턴, 웨이브, 밸런스 초안
- AI 프롬프트 원문
- 결과물 중 채택/수정/폐기 항목
- 게임 경험에 미친 영향

### Phase 4. 폴리싱 및 안정화

- [ ] UI 문구, 튜토리얼, 밸런스 조정에 AI를 사용했다.
- [ ] 플레이 테스트 결과를 AI에게 분석시킨 경우 기록했다.

기록해야 할 내용:

### Phase 6. 영상 및 최종 제출

- [ ] 영상 구성안 작성에 AI를 사용했다.

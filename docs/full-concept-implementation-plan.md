# 기획 원형 구현 플랜

작성일: 2026-07-30  
목적: 기획 담당이 설명한 원래 게임 의도를 전부 구현 가능한 방향으로 정리한다.  
범위: 현재 예선 빌드를 기반으로 하되, 단기 제출용 보강과 장기 완성형 구조를 분리한다.

## 1. 목표 정체성

### 장르

**방 단위로 진행하는 탑다운 핵앤슬래시 액션 RPG.**

참고 감각은 다음 둘을 섞는다.

- 아이작: 방을 거쳐가며 전투, 파밍, 선택이 반복된다
- 토치라이트 인피니트: 한 화면짜리 방보다 넓은 맵에서 다수의 잡몹을 빠르게 정리하며 나아간다

뱀서라이크와 구분되는 점:

- 공격을 완전히 자동 방치형으로 만들지 않는다
- 플레이어가 조준, 이동, 대시, 무기 운용, 콤보 유지를 직접 신경 쓴다
- 잡몹은 많이 나오지만 목적은 오래 버티기가 아니라 방 돌파와 보스 처치다
- 성장 보상은 웨이브 생존 보상이 아니라 방/보스/드랍을 통해 얻는다

### 한 줄 소개

> 현대인이 무의식의 이세계에서 양손의 실체화 장비로 무기를 만들어내고, 방을 돌파하며 보스의 기억 파편을 빼앗는 핵앤슬래시 액션 RPG.

예선 제출용으로 더 짧게 쓰면:

> 양손 무기를 실체화하고, 콤보와 보조능력으로 방을 돌파하는 탑다운 핵앤슬래시.

## 2. 핵심 경험

플레이어가 30초 안에 느껴야 하는 것:

1. 적이 많이 몰려오고 빠르게 죽는다
2. 방은 화면보다 넓고, 플레이어는 직접 움직이며 길을 찾는다
3. 양손 무기는 서로 다른 역할을 가진다
4. 콤보가 유지되면 전투력이 눈에 띄게 올라간다
5. 보스를 잡으면 특별한 보상이 나온다

한 판이 끝났을 때 기억해야 하는 것:

- "이번에는 활의 연사를 키워서 화면을 투사체로 덮었다"
- "검으로 상처를 쌓고 다른 무기로 터뜨렸다"
- "보스가 드랍한 장비 강화 때문에 다음 방이 달라졌다"
- "스토리는 설명되지 않았지만, 적과 장소가 주인공의 과거와 관련 있어 보였다"

## 3. 세계관 구현 방식

### 겉으로 보이는 이야기

플레이어는 현대인이다. 어느 순간 낯선 이세계에 끌려왔고, 양팔에는 벗겨지지 않는 실체화 장비가 붙어 있다. 플레이어는 이 장비로 검, 활, 비전, 방패 같은 무기 형태를 만들어내며 방을 돌파한다.

### 숨겨진 이야기

이세계는 실제 장소가 아니라 주인공의 무의식이다. 적들은 주인공의 과거 삶, 죄책감, 회피, 기억의 파편에서 나온다. 마지막까지 직접 말하지 않고, 오브젝트 텍스트와 아이템 설명으로만 암시한다.

### 구현 원칙

- 컷신 없음
- 대사 없음
- 강제 스토리 없음
- 방마다 1-2개의 조사 오브젝트
- 보스 드랍 아이템에 2-3줄 설명
- 엔딩에서만 반전의 가능성을 강하게 암시

예시 텍스트:

- `장갑은 처음부터 손에 있었다. 벗겨지지 않는다.`
- `갑옷 안에는 아무도 없었다. 그런데도 무거웠다.`
- `개를 키운 적이 있다. 이름은 기억나지 않는다.`
- `돌아가고 싶은지는 아직 확실하지 않다.`

## 4. 게임 구조

### 최종형 루프

```text
시작 장비 선택
  → 방 1 탐색/전투
  → 보조능력 선택 또는 드랍 획득
  → 방 2 탐색/전투
  → 중간 보스
  → 보스 드랍 장비 강화
  → 방 3-4 탐색/전투
  → 메인 보스
  → 영구 강화 선택
  → 다음 구역 또는 엔딩
```

### 예선형 루프

```text
무기 2종 선택
  → 넓은 방 1 정리
  → 보조능력 3택1
  → 넓은 방 2 정리
  → 보조능력 3택1
  → 넓은 방 3 정리
  → 보조능력 3택1
  → 보스 방
  → 보스 처치
  → 보스 드랍 연출/결과
```

예선형에서 반드시 추가할 것:

- 보스 처치 후 드랍 연출
- 드랍 아이템 설명
- 드랍이 실체화 장비를 강화한다는 메시지

실제 영구 저장은 예선에서 없어도 된다. 하지만 보스 드랍이 "이 게임의 원래 성장 축"임을 보여주는 장면은 있어야 한다.

## 5. 맵과 방

### 방 크기

방은 화면보다 넓다. 한 화면짜리 아레나가 아니라, 이동하며 적 무리를 찾아 정리하는 구조다.

권장 크기:

- 작은 방: 1600×1000
- 일반 방: 2400×1400
- 큰 방: 3000×1700
- 보스 방: 2000×1250 또는 2400×1400

### 방 타입

예선에서는 4개 고정 방으로 충분하다.

장기적으로는 다음 타입을 둔다.

| 방 타입 | 역할 |
| --- | --- |
| 전투 방 | 잡몹 무리를 정리한다 |
| 엘리트 방 | 강한 적 1-2기와 보조 무리 |
| 보상 방 | 보조능력, 회복, 장비 파편 |
| 서술 방 | 전투는 적고 오브젝트 텍스트가 많다 |
| 보스 방 | 기믹과 드랍이 있는 핵심 전투 |

### 미니맵

넓은 방에서는 미니맵이 필수다.

표시할 것:

- 플레이어 위치
- 남은 적 분포
- 출구
- 보스
- 서술 오브젝트
- 드랍 아이템

예선에서는 현재 구현된 고정 미니맵을 유지한다. 장기적으로는 방 연결 구조까지 보여주는 맵으로 확장한다.

## 6. 전투

### 공격 방식

기획 피드백에는 뱀서식 자동공격 언급이 있었지만, 최종 방향은 뱀서라이크가 아니다. 따라서 완전 자동공격은 피한다.

추천 방식은 **반자동 공격**이다.

- 기본값: 버튼을 누르고 있으면 해당 손 무기가 쿨다운마다 계속 나간다
- 조준: 마우스 방향
- 왼손: 좌클릭 홀드
- 오른손: 우클릭 또는 Shift 홀드
- 대시: Space

이 방식의 장점:

- 클릭 연타 피로를 줄인다
- 핵앤슬래시의 흐름이 살아난다
- 뱀서처럼 방치형이 되지 않는다
- 좌/우 무기를 직접 운용한다는 원안이 유지된다

### 적 밀도

잡몹은 많이 나오고 빨리 죽어야 한다. 단, 맞으면 아파야 한다.

원칙:

- 잡몹 체력은 낮게
- 무리 수는 많게
- 피격 무적 때문에 실제 받은 피해가 너무 낮아지면 개별 접촉 피해를 올린다
- 중장갑은 진행을 끊는 벽 역할
- 원거리 적은 도망만 치는 플레이를 막는 역할

## 7. 콤보

### 기획 의도

콤보는 한 번 채워서 스킬을 1회 쓰는 게 아니다. 콤보가 기준 이상으로 유지되는 동안 추가 효과가 계속 켜지는 상태다.

### 최종 규칙

- 기본 공격이 적중하면 해당 손의 콤보가 오른다
- 콤보 목표치에 도달하면 그 손 무기는 `각성 상태`가 된다
- 각성 상태 동안 기본 공격은 계속 나간다
- 발동 스킬은 일정 간격으로 자동 병행 발동한다
- 발동 스킬이 적중하면 콤보 지속시간이 갱신된다
- 일정 시간 적중하지 못하면 콤보가 끊긴다

### 왜 병행 발동인가

발동 스킬이 기본 공격을 대체하면 콤보 달성이 손해가 될 수 있다. 예를 들어 검의 기본 베기가 멸검 지대로 바뀌면 적이 지대 밖으로 나갈 때 초당 피해가 떨어진다. 따라서 발동 스킬은 대체가 아니라 추가 효과여야 한다.

### UI

- 각 손의 콤보 게이지를 분리한다
- 콤보가 켜진 손은 플레이어 주변에 해당 무기 색 링을 표시한다
- HUD에는 `왼손 검: 각성 중`, `오른손 활: 3/5`처럼 표기한다
- 보조능력이 어느 손/스킬에 붙었는지 항상 보인다

## 8. 무기와 스킬

무기는 손에 드는 장비 선택이다. 스킬은 무기가 실제로 내보내는 공격 방식이다.

| 무기 | 기본 스킬 | 각성/발동 스킬 | 역할 |
| --- | --- | --- | --- |
| 검 | 베기 | 멸검 | 근접 지속딜, 상처 |
| 활 | 화살 사격 | 연사 | 원거리, 약점 노출, 투사체 빌드 |
| 비전 | 비전 탄 | 비전단검 | 마법, 낙인, 비전 흐름 |
| 방패 | 밀치기 | 균열 파동 | 제어, 벽 충돌, 기절 |

### 양손 선택의 의미

두 무기를 고르는 이유가 분명해야 한다.

필요한 상호작용:

- 한 손으로 상태를 만들고 다른 손으로 소모한다
- 한 손은 잡몹 처리, 다른 손은 보스/제어 담당
- 보조능력을 한쪽에 몰아 강한 빌드를 만든다
- 콤보 유지가 손마다 달라 운용 선택이 생긴다

예선에서는 상처 소모 반응 하나로 시작한다.

장기적으로는 상태 반응을 늘리되, 12개 전부를 만들지 않는다. 각 상태당 대표 반응 하나만 둔다.

| 상태 | 기본 효과 | 대표 교차 반응 |
| --- | --- | --- |
| 상처 | 5스택 폭발 | 다른 무기로 때리면 스택당 피해 후 소모 |
| 약점 노출 | 받는 피해 증가 | 다음 큰 타격이 주변 약점 확산 |
| 낙인 | 비전 흐름 획득 | 낙인 소모 시 가까운 적 1기 전이 |
| 균열 | 기절 | 벽 충돌 시 충격파 확대 |

## 9. 보조능력

### 역할

보조능력은 한 판 안에서 스킬을 바꾸는 단기 성장이다.

보스 드랍과 구분:

- 보조능력: 이번 판의 스킬 형태를 바꾼다
- 보스 드랍: 실체화 장비 자체에 특별하고 영구적인 능력을 부여한다

### 몰아주기

한 스킬에 보조능력 2개가 붙을 때 가장 눈에 띄는 장면이 나온다.

예:

- 연사 + 다중투사체 + 갈래: 7발이 21발로 분열
- 멸검 + 지진 + 지속되는 평정: 넓고 오래가는 지대
- 균열 파동 + 지진 + 끌어내리는 지대: 적을 느리게 묶는 제어 장판

따라서 선택지는 이미 투자한 스킬 쪽으로 조금 기울어야 한다. 플레이어가 "이 빌드를 키우고 있다"는 감각을 받아야 한다.

### UI 개선

카드에는 반드시 다음을 표시한다.

- 보조능력 이름
- 붙을 손: 왼손/오른손
- 붙을 스킬: 기본/각성 스킬
- 예상 변화: `연사 5발 → 7발`, `피해 58 → 41`, `갈래 3`

## 10. 보스

### 기획 의도

보스는 여러 종류여야 하고, 잡몹보다 훨씬 크며, 각자 기믹이 있어야 한다. 보스는 단순히 체력이 큰 적이 아니라 장비 성장의 원천이다.

### 예선 최소 구현

예선에서 당장 필요한 것은 보스 1종을 유지하더라도, 보스가 “게임의 핵심 보상 구조”를 보여주는 것이다.

필수:

- 보스 크기 확대
- 보스 전용 패턴 2개
- 보스 체력 단계별 변화
- 처치 시 드랍 연출
- 드랍 아이템 3택1 또는 1개 확정 지급
- 결과 화면에 획득한 기억 파편/장비 강화 표시

### 보스 1: 문지기

역할: 첫 번째 관문. 플레이어가 이 세계의 규칙을 받아들이는 보스.

패턴:

1. 돌진
   - 플레이어를 향해 예고선을 띄운 뒤 빠르게 돌진
   - 벽에 부딪히면 잠시 멈춤

2. 사냥개 호출
   - 체력 70%, 35%에서 사냥개 무리 소환
   - 핵앤슬래시 감각을 보스전에서도 유지

3. 문 닫기
   - 방 가장자리 일부가 어두워지며 이동 가능 영역이 잠시 좁아짐
   - 대시 타이밍을 요구

드랍:

- `문지기의 파편`
- 효과: 실체화 장비 슬롯 +1 또는 다음 판 시작 무기 하나 강화
- 설명: `문은 열리지 않았다. 다만 손의 장갑이 조금 더 무거워졌다.`

### 보스 2: 껍데기의 왕

역할: 빈 갑옷 설정을 확장하는 보스.

패턴:

1. 갑옷 파편 투척
2. 방패형 전방 가드
3. 빈 껍데기 소환

드랍:

- `빈 갑주의 심`
- 효과: 방패/중장갑 관련 영구 강화

### 보스 3: 몰이꾼 우두머리

역할: 원거리 압박과 위치 선정 보스.

패턴:

1. 부채꼴 칼 투척
2. 표식 후 저격
3. 사냥개와 몰이꾼 동시 소환

드랍:

- `끊어진 목도리`
- 효과: 활/비전 투사체 관련 영구 강화

## 11. 보스 드랍과 영구 성장

### 목적

기획자가 말한 핵심은 보조능력과 별개의 성장 축이다. 보스가 드랍하는 특별한 아이템은 실체화 장비를 강화하거나 특정 무기에 영구 능력을 부여한다.

### 저장 없이도 가능한 예선형

예선 빌드는 브라우저 링크로 바로 실행되어야 하므로 저장 시스템 없이도 보여줄 수 있어야 한다.

예선 대안:

- 보스 처치 후 `기억 파편 획득` 화면 표시
- 그 자리에서 장비 강화 3택1 제시
- 선택하면 결과 화면에 `해금된 실체화 능력`으로 기록
- 재시작 시 실제 영구 적용은 하지 않아도 된다

이렇게 하면 보스 드랍의 존재와 방향은 보여주되, 저장/해금/메타 진행 전체를 만들지 않아도 된다.

### 장기형

브라우저 `localStorage`에 영구 해금을 저장한다.

영구 강화 예:

| 아이템 | 출처 | 효과 |
| --- | --- | --- |
| 문지기의 파편 | 문지기 | 시작 시 선택한 첫 무기 기본 피해 +5% |
| 빈 갑주의 심 | 껍데기의 왕 | 방패 벽 충돌 피해 +20% |
| 끊어진 목도리 | 몰이꾼 우두머리 | 투사체 속도 +10% |
| 흐린 장갑끈 | 서술 방 | 콤보 지속시간 +0.5초 |

드랍 방식:

- 첫 처치: 핵심 아이템 확정
- 반복 처치: 낮은 확률로 희귀 변형 드랍
- 이미 보유한 아이템은 강화 단계로 전환

## 12. 적

### 사냥개

- 개 형태
- 빠르게 접근
- 체력 낮음
- 무리로 압박
- 초반부터 많이 나와 핵앤슬래시 감각을 만든다

### 껍데기

- 중장갑을 입었지만 안은 비어 있음
- 느림
- 체력 높음
- 창이나 검을 들고 전진
- 다른 잡몹 사이에서 길을 막는다

### 몰이꾼

- 가죽 장비
- 하관을 마후라로 가림
- 활 또는 투척 칼 사용
- 플레이어가 도망만 치는 것을 막는다

### 보스

- 일반 적보다 확실히 큼
- 체력만 큰 적이면 안 됨
- 최소 2개 패턴
- 보스 처치가 장비 성장과 연결되어야 함

| 종류 | 지속 | 예 |
| --- | --- | --- |

| 희귀 유물 | 영구 또는 장기 | 특정 무기 전용 특수 능력 |

### 예선 우선순위

1. 보스 드랍 연출
2. 보스 드랍 아이템 설명
3. 결과 화면에 획득 표시
4. 실제 영구 저장은 후순위

## 14. 아트와 사운드

### 아트

기획 반영 핵심:

- 플레이어는 현대 복장
- 양팔에 실체화 장비
- 배경은 현대가 아닌 이세계 던전
- 적은 주인공의 과거와 관련된 불편한 형상
- 보스는 잡몹과 명확히 다른 크기

### 사운드

효과음은 체감 완성도에 매우 크다.

예선 필수 4개:

- 근접 휘두름
- 투사체 발사
- 명중
- 처치

와우포인트용 추가:

- 상처 폭발
- 벽 충돌
- 콤보 각성
- 보스 드랍

## 15. 구현 단계

### Stage A. 현재 예선 빌드 정렬

목표: 기획자의 새 컨셉이 현재 빌드에서 모순 없이 보이게 한다.

작업:

- `game-scope.md`를 핵앤슬래시/넓은 방 중심으로 갱신
- `action-tracker.md`의 옛 횡스크롤 재확정 문구 제거
- 보조능력 선택 카드에 손/스킬/변화량 더 명확히 표시
- 클릭 홀드 또는 Shift 홀드로 반자동 공격 도입 검토
- 현재 미커밋 버그 수정(`showOffer`, `showResult` scrollFactor) 검증 후 커밋

완료 기준:

- 문서에서 탑다운 웨이브 로그라이트/횡스크롤 보스전/핵앤슬래시가 서로 충돌하지 않는다
- 한 판 구조가 방 돌파 핵앤슬래시로 설명된다
- 플레이테스트 문서가 최신 조작/방 구조/미니맵을 반영한다

### Stage B. 보스전 최소 기믹

목표: 보스가 단순 큰 추적자가 아니게 한다.

작업:

- 보스 패턴 상태 머신 추가
- 돌진 예고선
- 체력 구간별 사냥개 소환
- 보스 피격/분노 연출
- 보스 처치 드랍 오브젝트

완료 기준:

- 보스전에서 일반 방과 다른 패턴이 보인다
- 보스가 최소 2번 이상 행동을 바꾼다
- 처치 후 드랍 연출이 나온다

### Stage C. 보스 드랍/장비 강화

목표: 보스 드랍이 보조능력과 다른 성장 축임을 보여준다.

작업:

- `BossDrop` 데이터 정의
- 드랍 화면 UI
- 장비 강화 설명 텍스트
- 결과 화면에 획득 표시
- 장기형으로는 `localStorage` 저장

예선 완료 기준:

- 보스 처치 후 `기억 파편`을 얻는다
- 플레이어가 이것이 실체화 장비 강화라는 것을 이해한다
- 실제 영구 저장이 없어도 게임의 방향은 보인다

### Stage D. 보스 다종화

목표: 기획자가 말한 “보스는 한 종류면 안 됨”을 실제 콘텐츠로 확장한다.

예선에서 꼭 할 필요는 없지만, 한다면 가장 작은 방식:

- 한 판에는 보스 1기만 등장
- 시작 시 또는 방 진입 시 보스 종류를 2종 중 하나로 결정
- 보스별 색, 패턴, 드랍 이름만 다르게 시작

추천 최소 2종:

- 문지기: 돌진 + 사냥개 호출
- 껍데기의 왕: 방어 자세 + 갑옷 파편 투척

완료 기준:

- 두 보스가 화면에서 다르게 보인다
- 공격 패턴이 다르다
- 드랍 이름과 설명이 다르다

### Stage E. 파밍 확장

목표: 핵앤슬래시 감각을 강화한다.

작업:

- 잡몹 낮은 확률 회복 구슬
- 엘리트 적 드랍
- 보스 희귀 드랍
- 드랍 텍스트 로그

예선에서는 보스 드랍 하나만 먼저 넣는다.

## 16. 우선순위

기획자가 말한 것을 전부 살리는 기준의 우선순위:

1. 보스 드랍 연출과 장비 강화 설명
2. 보스 패턴 2개
3. 반자동 공격 홀드 입력
4. 보조능력 카드 정보 강화
5. 실제 효과음 4개
6. 보스 2종화
7. 영구 저장
8. 절차적 방/분기 맵
9. 상점/파밍 테이블 확장

이 순서인 이유:

- 1-2는 기획자가 강하게 말한 “보스 중심 파밍”을 직접 살린다
- 3은 핵앤슬래시의 손 피로를 줄인다
- 4는 현재 구현된 성장 시스템을 이해 가능하게 한다
- 5는 체감 완성도를 크게 올린다
- 6 이후는 콘텐츠와 QA 비용이 커진다

## 18. 제출 문서에서의 설명

게임 소개 문서에는 이렇게 설명한다.

> 이 게임은 한 화면 방에 머무는 생존형 로그라이트가 아니라, 넓은 방을 돌파하며 무기 조합을 성장시키는 탑다운 핵앤슬래시다. 플레이어는 현대인으로, 양팔의 실체화 장비를 통해 서로 다른 무기를 만들어낸다. 보조능력은 한 판 안의 스킬 빌드를 바꾸고, 보스가 떨어뜨리는 기억 파편은 실체화 장비의 더 깊은 성장 가능성을 보여준다.

AI 활용 기술 문서에는 이렇게 설명한다.

> 초기 AI 구현은 탑다운 웨이브 생존에 가까워 기획자의 핵앤슬래시/방 돌파/보스 파밍 의도와 어긋났다. 이후 기획 피드백을 기준으로 방 구조, 넓은 맵, 미니맵, 잡몹 밀도, 콤보 지속, 보조능력 집중, 상처 교차 반응, 배경 서술을 재정렬했다. 이 과정에서 AI 제안을 그대로 쓰지 않고, 기획자가 원한 장르 감각을 기준으로 채택·수정·폐기했다.

## 19. 결정 필요

5. 보스 드랍 아이템의 이름과 설명 톤

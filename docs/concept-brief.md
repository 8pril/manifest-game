# 세계관·이름 요청

작성일: 2026-07-27  
작성자: 기획 담당이 채운다

## 왜 지금 필요한가

**아트 생성이 이것 없이는 시작할 수 없다.**

`docs/art-spec.md`에 이미지 14장의 크기·색·파일명은 정해져 있다. 그런데 프롬프트에 들어갈 단어(주인공이 뭐로 생겼는지, 적이 무엇인지, 장소가 어디인지)는 개발 쪽에서 임시로 채워놓은 상태다. `a lone swordfighter`, `armored brute`, `dark carapace` 같은 것들인데 **전부 근거 없이 지어낸 값이다.**

이대로 생성하면 그 임시 단어가 게임의 비주얼 정체성이 되어 굳는다. 나중에 다른 그림을 갖고 있었다는 걸 알게 되면 14장을 다시 뽑아야 한다.

제출물 3번(게임 소개 문서)도 `게임 제목 및 한 줄 소개`를 필수로 요구한다. 어차피 정해야 한다.

## 원안에 없는 것

`01. 기획초안.xlsx`와 `02. 전투시스템 초안.xlsx`를 전부 확인했다. 문자열 236개가 전부 전투 수치와 시스템이고, **세계관·배경·제목·주인공에 대한 언급이 하나도 없다.** 시트의 `컨셉` 열도 "근접 지속딜" 같은 전투 역할이다.

즉 이 부분은 아직 아무도 정하지 않았다. 백지가 맞다.

## 이미 정해져 있는 제약

맨바닥은 아니다. 시스템이 이미 몇 가지를 암시한다. 이걸 뒤집어도 되지만, 뒤집으면 시스템 쪽도 같이 손봐야 한다.

- **`실체화`** — 무기를 그 자리에서 꺼내 쓴다는 개념. 원안 첫 시트 이름이 이것이다. 가장 강한 훅이다
- **`비전`, `낙인`, `균열`, `벌어진 상처`, `점화`, `동결`** — 주술적·의식적 어휘. 기계나 총기보다 마법 쪽에 가깝다
- **웨이브 3 + 보스** — 어딘가로 진격하는 게 아니라 몰려오는 것을 버티는 구조. 침입보다 방어나 시련에 가깝다
- **한 판 3-5분, 매번 다시 시작** — 긴 서사보다 반복되는 상황에 어울린다

## 채워야 할 것

### 1. 게임 제목

```
제목:
```

한글이든 영문이든 상관없다. 저장소 이름은 제목과 무관하게 지어놨으니 뭐가 되든 플레이 링크가 깨지지 않는다.

### 2. 한 줄 소개

```
한 줄 소개:
```

제출물 3번에 그대로 들어간다.

### 3. 주인공

```
누구인가:
왜 싸우는가:
무기를 '실체화'한다는 게 무엇인가 (어디서 꺼내오는가):
겉모습 (사람인가, 형체가 있는가, 무엇을 걸치고 있는가):
```

### 4. 적

적은 지금 4종이고 각각 행동이 다르다. **이름과 정체를 붙여달라.**

| 현재 이름 | 행동 | 붙일 이름 | 무엇인가 / 어떻게 생겼는가 |
| --- | --- | --- | --- |
| 추적자 | 곧장 달려든다 | | |
| 중장갑 | 느리고 단단하다 | | |
| 사수 | 거리를 두고 쏜다 | | |
| 보스 | 마지막에 나온다 | | |

### 5. 장소

```
여기는 어디인가:
바닥은 무엇으로 되어 있는가:
```

바닥 타일 이미지를 만들어야 해서 재질이 필요하다.

### 6. 톤

```
참고가 될 만한 작품 / 이미지 / 분위기:
피하고 싶은 방향:
```

"이런 느낌"이라고 떠오르는 게임이나 그림이 있으면 이름만 적어도 된다. 프롬프트 단어를 고르는 데 쓴다.

## 답을 받으면

개발 쪽에서 `docs/art-spec.md`의 프롬프트를 이 내용으로 다시 쓴다. 그다음 생성을 시작하면 된다.

**분량은 짧아도 된다.** 각 항목 한두 줄이면 프롬프트를 쓰기에 충분하다. 길게 쓰는 것보다 **구체적인 명사**가 도움이 된다. "어두운 분위기"보다 "녹슨 철제 제단"이 프롬프트에서 훨씬 잘 작동한다.

## 정하지 않아도 되는 것

시간을 아끼기 위해 명확히 해둔다. 이번 예선에서는 아래가 필요 없다.

- 긴 스토리나 설정집
- 등장인물 관계도
- 지명·연대기
- 게임 내 대사나 컷신

한 판 3-5분에 서사가 들어갈 자리가 없다. **그림을 그리는 데 필요한 만큼만** 있으면 된다.

## 지금 막혀 있는 결정 5건

**아래가 이번 플레이 테스트로 닫아야 할 것들이다.** 나머지는 참고 정보다.
전부 `docs/action-tracker.md`에 자세히 적혀 있다.

### 가장 급한 둘 — 심사자가 1회차만 본다

**D4. 비전을 1회차에 보여줄 것인가**

비전은 지금 **최종 보스 보상**이다. 즉 얻는 즉시 판이 끝나고, 실제 사용은 다음 판부터다.
**심사자가 1회차만 플레이하면 무기 4종 중 하나를 아예 못 본다.**

| 안 | 내용 |
| --- | --- |
| A | 현행 유지. 최종 보스 보상의 무게가 크고 영구 성장 구조가 명확하다 |
| B | 비전을 `파편 회랑` 보상으로 앞당긴다. 1회차에 4종을 다 보여줄 수 있다 |
| C | 최종 보스 직전에 짧은 마을을 넣어 장착 후 보스전에 들어간다 |

**D6. 보조형스킬을 1회차에 보여줄 것인가**

같은 문제다. 보조형스킬의 유일한 출처가 최종 보스라 **1회차에는 마을 패널의 보조 슬롯
8칸이 전부 비어 있고 채울 수 없다.**

조합은 이 게임의 핵심 셀링 포인트다. 보조형스킬 18종, 태그 검증, 시너지 반응, DPS 벤치가
전부 이 시스템을 위해 있는데 1회차에 한 번도 안 보인다.

| 안 | 내용 |
| --- | --- |
| A | `해금 시험장` 또는 `파편 회랑` 보상으로 1~2종 지급. 첫 마을은 0개 유지 |
| B | 두 방 중 하나에 보상 오브젝트를 두고 드랍 |
| C | 현행 유지. 조합은 2회차부터 |

> **D4와 D6은 같은 성질이다 — 보상이 최종 보스에 몰려 1회차에 못 쓴다.**
> 둘을 함께 판단하는 편이 낫다. 30~60초 영상에도 직결된다.

### 플레이 감각으로 정할 셋

**D3. 방패가 보스전에서 쓸 만한가** (아래 3번 항목에서 판단)

**D5. 각성 중 방패가 얼마나 단단해야 하는가**

보호 시간이 지금 240ms 고정이라 가동률이 상황마다 다르다.

| 상황 | 발동 간격 | 보호 시간 | 가동률 |
| --- | --- | --- | --- |
| 밀치기 | 420ms | 240ms | 57% |
| 균열 파동(각성 중) | 1200ms | 240ms | **20%** |

각성이 곧 "딜 시간"이라 물러지는 게 맞다고 보면 현행 유지, 각성 중에도 단단해야 한다고
보면 발동 간격에 비례하도록 바꾼다.

**콤보가 선택형이 되면서 이 문제의 범위가 줄었다.** `콤보 개방`을 안 붙인 방패는 계속
밀치기만 쓰므로 가동률이 57% 하나로 고정된다. 20%로 떨어지는 구간은 콤보 빌드에만 있다.

**D1. 해금이 다음 판에 남아야 하는가**

지금은 해금한 무기·보조형스킬이 판을 넘어 남는다(손에 든 무기와 1번 방 R링만 매 판 잠긴다).
매 판 처음부터 다시 얻는 게 맞는지, 지금처럼 쌓이는 게 맞는지.

## 확인할 것

무기 조합은 12가지지만 전부 할 필요는 없다. **3~4가지만** 골라도 충분하다.

1. **한 판 소요 시간.** 목표는 3~5분.

2. **첫 보스까지의 손맛.** 검 기본 공격만으로 방 1개와 보스 하나를 넘는 구간이다.
   지루한지, 아니면 첫 보상이 그만큼 크게 느껴지는지.

3. **방패의 보스전 역할** → **D3·D5가 여기서 갈린다.**

   방패는 피해가 가장 낮은 대신 두 가지를 갖는다. **방패로 공격할 때만 0.24초짜리
   보호 시간이 열린다.** 손에 들고만 있으면 켜지지 않는다. 그 시간 안에 맞으면
   에너지 보호막 45가 체력보다 먼저 닳고, 받는 피해도 45%로 준다.
   보호막은 재생되지 않고 방을 클리어해야 회복된다.

   HUD의 보호막 바는 방패를 손에 들고 있으면 계속 보이고, 보호 시간에만 밝아진다.
   그리고 **보스는 넉백·기절에 걸리지 않는다.**

   > **방패로 보스를 상대할 때, 막으면서 버틴다는 느낌이 드는가.**
   > **특히 각성 5초 동안 더 강해진 느낌인가, 더 위험해진 느낌인가.**

   보호막이 "방을 버티는 자원"이 아니라 "가끔 한 대 막아주는 것"으로 느껴진다면
   보호 시간을 늘리는 쪽을 검토한다.

4. **첫 문지기 난이도.** 배치는 보스 1 + 사냥개 4지만, 보스가 체력 70%/35%에서 사냥개를
   소환한다. 자동 검증 봇 기준으로 한때 생존 적이 10마리까지 늘었다.
   기획 의도가 "1~2번 방은 학습 구간"이었는데 소환이 그걸 되돌리고 있는지.

5. **투사체 무기의 보스전 속도.** 여러 발이 큰 대상에게 전부 꽂히는 문제 때문에
   발당 피해에 전역 보정을 넣었다(총합 배율 = 투사체 수^0.6).
   그만큼 콤보스킬 피해를 올렸지만(연사 36→51, 비전단검 32→54), 실제로 답답한지.

6. **몰이꾼이 카이팅을 막는지.** 활을 든 적이고 `해금 시험장`부터 나온다.
   너무 아픈지, 무시해도 되는지.

7. **상태이상이 눈에 보이는지.** 적 머리 위 색 점에 더해 발동 순간에 연출이 있다.
   상처 폭발(붉은 링), 낙인 소모(보라 파동 + 플레이어 오라), 기절(흰 링 + 플래시),
   벽 충돌(충격 + 흔들림).

   - **확인 필요:** 상처 폭발은 5스택이 필요한데 베기 46 피해 기준 사냥개(체력 52)와
     몰이꾼(60)은 2타에 죽어 도달하지 못한다. 껍데기(260)와 보스에서만 터진다.
     이대로 "단단한 적을 무너뜨리는 마무리"로 둘지.

8. **콤보 발동 빈도.** 5타가 너무 빠른지 느린지.

   - 콤보는 **적 하나 맞힐 때마다** 1씩 오른다. 근접 무기로 3마리를 한 번에 쓸면 3 오른다.
     적이 몰린 상황에서 훨씬 자주 터진다. 의도한 맛인지.

9. **검이 필수 픽처럼 느껴지는지.** 상처가 쌓인 적을 다른 무기로 때리면 스택당 추가 피해가
   들어간다. 상태이상 4종 중 상처에만 이 반응이 있어 **검을 안 고르면 손해**라고 느껴지는지.

## 한 판 구조 (참고)

**검 1종으로 시작한다.** 오른손은 비어 있고, 콤보스킬(멸검)도 아직 없다.
즉 처음에는 **검 기본 공격만** 나간다. 첫 보스를 잡아야 무기와 콤보스킬이 열린다.

```
검 1종 시작 → 흐린 입구 → 첫 문지기(보스)
            → 바닥 드랍에 가까이 가서 자동 획득 → 마을(NPC와 F 대화)
            → 해금 시험장 → 파편 회랑 → 무너진 문(보스) → 승리 / 패배
```

**보상은 바닥에 떨어진다.** 금색 마름모가 남고, 가까이 가면 **자동으로 획득된다.**
**줍기 전에는 출구가 열리지 않는다.**

**마을은 걸어다니는 방이다.** 들어가도 아무 창이 뜨지 않는다. 후드를 쓴 관리인 NPC에게
다가가 `F 대화`로 장비 설정 패널을 연다. 다음 전투는 오른쪽 출구로 걸어 나가면 시작된다.

**방은 화면보다 크다.** 카메라가 따라가고, 화면 밖의 적과 출구는 가장자리 화살표로 표시된다.
**방마다 바닥 색조와 장식물이 다르다.**

| 입력 | 동작 |
| --- | --- |
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 | 왼손 무기 |
| 우클릭 **또는 Shift** | 오른손 무기 |
| Space | 대시 (대시 중 무적, 적을 통과함) |
| F | 마을 NPC 대화 |
| R (누르고 있기) | 무기 교체 링 메뉴 — 첫 보스 이후 해금 |
| R (마을 패널이 열려 있을 때) | 패널 닫기 |
| R (판이 끝난 뒤) | 다시 시작 |
| P 또는 ESC | 일시정지 메뉴 |
| Shift+R (일시정지·결과 화면에서) | **저장 기록 지우고 처음부터** |

### 콤보 — **2026-08-09에 선택형으로 바뀌었다**

**콤보는 더 이상 모든 무기의 기본 규칙이 아니다.** 예전에는 누구나 5대를 채워야 강한
기술이 나갔는데, 그 5대에 아무 판단이 없어 통행세였다. 지금은 **고르는 것**이다.

첫 보스가 보조2형 `콤보 개방`을 준다. 마을에서 무기에 붙이면 그 무기만 이렇게 된다.

```
기본 공격 5회 명중 → 강화기술로 전환 → 5초 안에 못 맞히면 풀림
```

**붙이지 않은 무기는 기본 공격만 쓴다.** 멸검·연사·비전단검·균열 파동은 이제 모두가
거치는 관문이 아니라 `콤보 개방`을 고른 사람이 보는 기술이다. 화면 아래 콤보 배지도
붙인 무기에만 뜬다.

보조 배치도 이에 맞춰 바뀌었다.

| | 붙는 곳 |
| --- | --- |
| 보조2형: 조건/시너지 | **기본 공격.** 조건과 시너지라 평소 쓰는 공격에 걸려야 의미가 있다 |
| 보조1형: 성능 보강 (`콤보 개방` 있을 때) | 강화기술 |
| 보조1형: 성능 보강 (`콤보 개방` 없을 때) | **기본 공격.** 강화기술이 발동하지 않으니 거기 붙이면 칸이 죽는다 |

> **이번 플레이 테스트에서 이걸 봐 주면 좋겠다.**
> **`콤보 개방`을 안 붙인 쪽이 심심한지, 아니면 그것대로 할 만한지.**
> 붙인 쪽과 안 붙인 쪽을 번갈아 해보는 게 가장 빠르다 — `?combo=1`을 주소 뒤에 붙이면
> 처음부터 붙은 상태로 시작한다.

### 저장

진행은 브라우저에 저장된다. 해금한 무기·콤보스킬·보조형스킬과 마을 세팅이 다음 판에 남는다.
단 **손에 든 무기는 매 판 검 1종으로 돌아가고, 1번 방에서는 R링이 열리지 않는다.**
도입부를 매 판 똑같이 보이게 하려는 의도다. (이 범위가 맞는지가 **D1**이다.)

처음부터 다시 보고 싶으면 **P → Shift+R**.

## 수치 직접 조정

밸런스 수치는 5개 파일에 모여 있다. 코드를 몰라도 숫자만 바꾸면 된다.

| 파일 | 조정 대상 |
| --- | --- |
| `src/game/enemy.ts` | 적 체력·속도·피해·사거리, 보스 패턴 임계값 |
| `src/game/rooms.ts` | 방별 적 구성, 방 크기, 방 보상 |
| `src/data/weapons.ts` | 무기 피해·사거리·쿨다운·콤보 간격 |
| `src/game/combo.ts` | 콤보 요구치(현재 5)·지속시간(현재 5초) |
| `src/game/run.ts` | 플레이어 체력·무적 시간·방패 보호막 |

**바꾼 내용은 직접 커밋한다.** 커밋 기록도 심사 대상이므로 기획 담당 명의로 남는 편이
팀원 롤 기술서 작성에 유리하다.

수치를 바꾼 뒤에는 `npm test`를 돌린다. `src/game/dps.bench.test.ts`가 무기별 각성 배율을
계산해 1.5~2.5배 범위를 벗어나면 실패시킨다. 한 무기만 세지거나 약해지는 것을 막는 장치다.

### 개발용 진입 파라미터

주소 뒤에 붙여 특정 방·무기로 바로 시작할 수 있다. **방 번호는 1부터다.**
배포 링크에서도 그대로 쓸 수 있다.

```
?wave=2                  첫 문지기 방부터
?left=bow&right=arcane   무기를 지정해서 시작
?wave=4&left=shield      둘 다 지정
?town=1                  첫 마을부터
?combo=1                 콤보 개방을 미리 장착 (콤보 빌드로 바로 시작)
```

`left`, `right`, `wave`, `town`을 지정하면 저장된 진행을 무시하고 **저장도 하지 않는다.**
기존 기록이 훼손되지 않으므로 마음껏 써도 된다.

## 알아둘 것

- 아트는 전부 반영됐다. 타이틀 배경, 방별 색조와 장식물, 무기 그림까지 들어가 있다
- 효과음은 들어갔다(공격·피격·처치·콤보·보스 예고·보상). **음소거 기능은 아직 없다**
